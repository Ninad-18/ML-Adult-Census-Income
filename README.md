# Adult Census Income – Data Science Lab Project

## 📌 Project Overview
This project performs complete data analysis and machine learning modelling on the Adult Census Income dataset. The objective is to predict whether a person's income exceeds $50K per year based on demographic attributes.

The project consists of 11 structured experiments covering:

- Data Preparation
- Exploratory Data Analysis
- Outlier Detection
- Data Scaling
- Class Imbalance Handling (SMOTE)
- Statistical Hypothesis Testing
- Regression & Classification Modelling
- Clustering
- Apache Spark EDA

---

## 📊 Dataset
Dataset: Adult Census Income Dataset  
Target Variable: `income` (<=50K, >50K)

---

## 🧪 Experiments Performed

1. Data Preparation using NumPy & Pandas
2. Exploratory Data Analysis (Matplotlib & Seaborn)
3. Outlier Detection (IQR & Z-score)
4. Normalization / Standardization
5. Handling Class Imbalance using SMOTE
6. Train-Test Split Validation using Two-Sample Z-Test
7. Statistical Hypothesis Testing (T-test & Chi-Square)
8. Logistic Regression
9. Decision Tree & Random Forest Classification
10. K-Means Clustering with PCA Visualization
11. Exploratory Data Analysis using Apache Spark

---

## 📈 Key Results

- Logistic Regression Accuracy: ~80-85%
- Random Forest Accuracy: ~85-88%
- Significant statistical relationship found between demographic features and income.
- Clustering revealed distinct population segments.
